What is Polymorphism?

Polymorphism is an important feature of Object-Oriented Programming.

Simple Meaning:

"Poly" means many and "morph" means forms.

So, polymorphism means one thing can take many forms.

In Java, the same method name can perform different actions depending on the situation.

Real-World Example

🔊 Sound

A dog makes a barking sound.

🐱 Cat

A cat makes a meowing sound.

🐄 Cow

A cow makes a mooing sound.

The action is sound(), but different animals perform it differently.

Method Overloading

Method overloading means having multiple methods with the same name but different parameters. 

class Calculator {

    int add(int a, int b) {
        return a + b;
    }

    int add(int a, int b, int c) {
        return a + b + c;
    }

}

Both methods are named add(), but they accept different numbers of parameters.

Method Overloading Example

Calculator calc =
    new Calculator();

System.out.println(calc.add(10, 20));

System.out.println(
    calc.add(10, 20, 30)
);
30

How Method Overloading Works

Different Parameters

Methods can have different numbers of parameters.

Different Data Types

Parameters can have different data types.

Same Method Name

The overloaded methods must have the same method name.

Method Overriding

Method overriding happens when a child class provides its own implementation of a method already defined in the parent class. 

class Animal {

    void sound() {
        System.out.println("Animal makes sound");
    }

}

class Dog extends Animal {

    void sound() {
        System.out.println("Dog barks");
    }

}

The Dog class overrides the sound() method of Animal.

Method Overriding Example

Dog dog =
    new Dog();

dog.sound();
Dog barks

Run-Time Polymorphism

Run-time polymorphism occurs when a parent class reference refers to a child class object and the overridden method is selected at runtime. 

Animal animal =
    new Dog();

animal.sound();
Dog barks
Even though the reference type is Animal, the actual object is Dog. Therefore, Dog's overridden sound() method runs.

Overloading vs Overriding

Overloading Overriding
Same class usually Parent and child classes
Same method name Same method name
Different parameters Same method signature
Compile-time Run-time
Does not require inheritance Requires inheritance

Benefits of Polymorphism

🔄 Flexibility

The same interface or method can work with different objects.

♻️ Reusability

Common code can be reused with different implementations.

🧩 Organization

Programs can be designed around common parent types.

📈 Extensibility

New child classes can provide their own behavior.
