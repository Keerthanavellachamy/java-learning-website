What is OOP?

OOP stands for Object-Oriented Programming. It is a programming approach where we organize a program using objects and classes.

Simple Meaning: OOP allows us to represent real-world things such as students, cars, mobile phones and bank accounts as objects in a program.

Java is mainly an object-oriented programming language. Most Java applications use classes and objects to organize their code.

Real-World Examples

🚗 Car

A car can have properties such as brand, color and speed.

🎓 Student

A student can have a name, age, register number and marks.

🏦 Bank Account

A bank account can have an account number, holder name and balance.

📱 Mobile

A mobile can have a brand, model, price and storage.

Class and Object

What is a Class?

A class is like a blueprint. It defines what data and behavior an object can have. 

class Student {

    String name;
    int age;

}

Creating an Object

An object is an actual instance of a class. We use the new keyword to create an object. 

Student student1 = new Student();

student1.name = "Keerthana";
student1.age = 20;

System.out.println(student1.name);
System.out.println(student1.age);
Remember:
Class = Blueprint
Object = Real instance created from the blueprint

Understanding the Code

class

Defines a new class in Java.

Student

Name of the class.

new

Creates a new object in memory.

student1

Reference variable that refers to the object.

Multiple Objects

We can create multiple objects from the same class. Each object can contain different values. 

Student student1 = new Student();
Student student2 = new Student();

student1.name = "Keerthana";
student2.name = "Amirtha";

System.out.println(student1.name);
System.out.println(student2.name);

Four Pillars of OOP

01

Encapsulation

Wrapping data and methods together inside a class.

02

Inheritance

Allows one class to get properties and behavior from another class.

03

Polymorphism

Allows the same method or interface to behave differently.

04

Abstraction

Hides unnecessary implementation details and shows only essential information.

OOP Concepts in Simple Words

Concept Simple Meaning Example
Encapsulation Protect and organize data Bank Account
Inheritance Reuse properties from another class Car → Vehicle
Polymorphism Same method, different behavior Animal sounds
Abstraction Hide complex implementation ATM

Benefits of OOP

♻️ Code Reusability

Existing code can be reused using classes and inheritance.

🔧 Easy Maintenance

Code can be organized into separate classes, making changes easier.

🔐 Data Security

Encapsulation helps protect data from unwanted access.

📦 Organization

Large programs can be divided into smaller and manageable components.

📈 Scalability

OOP makes it easier to extend applications as they grow.

🛠️ Easy Debugging

Problems can be isolated within individual classes and methods.
