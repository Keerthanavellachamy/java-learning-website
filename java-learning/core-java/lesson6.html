What is Abstraction?

Abstraction is the process of hiding internal implementation details and showing only the necessary information.

Simple Meaning:

Abstraction means "show what is necessary and hide what is not necessary."

For example, when you use an ATM, you select options such as Withdraw or Deposit. You do not need to know how the ATM internally communicates with the bank server.

Real-World Example

🚗 Car

You use the steering wheel and pedals. You do not need to know the internal engine mechanism.

🏧 ATM

You enter your PIN and choose an option. The internal banking process is hidden.

📱 Mobile

You tap an app icon without knowing the internal code running the application.

Abstraction in Java

Java mainly provides abstraction using:

Abstract Class

A class declared using the abstract keyword.

Interface

An interface can define a contract that classes implement.

Abstract Class

An abstract class is a class that cannot be directly used to create an object. 

abstract class Animal {

    void eat() {
        System.out.println("Animal eats");
    }

}
The keyword abstract is used before the class name.

Abstract Method

An abstract method is a method that has a declaration but does not have a body. 

abstract class Animal {

    abstract void sound();

}
Notice the semicolon after sound().

There is no method body because the child class will provide the implementation.

Abstract Class Example

abstract class Animal {

    abstract void sound();

    void eat() {
        System.out.println("Animal eats");
    }

}


class Dog extends Animal {

    void sound() {
        System.out.println("Dog barks");
    }

}

Using an Abstract Class

Dog dog =
    new Dog();

dog.sound();
dog.eat();
Dog barks
Animal eats

Why Use Abstract Classes?

🔒 Hide Details

Internal implementation can be hidden from the user.

📋 Common Structure

A parent class can define common methods and behavior.

🧩 Child Implementation

Child classes can provide their own implementation.

Important Rules

Rule Explanation
Abstract class Cannot be directly instantiated.
Abstract method Does not have a method body.
Child class Must implement abstract methods.
Normal method Can have a complete implementation.
Keyword The keyword is abstract.

Abstraction vs Encapsulation

Abstraction Encapsulation
Hides implementation details Protects data and controls access
Focuses on what an object does Focuses on how data is accessed
Uses abstract classes and interfaces Uses private fields and methods

Interface Preview

Interfaces are another important way to achieve abstraction in Java. You will learn interfaces in detail in Lesson 8. 

interface Animal {

    void sound();

}
Interfaces define what a class should do. The implementing class provides the actual behavior.
