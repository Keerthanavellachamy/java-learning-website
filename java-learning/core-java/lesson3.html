What is a Constructor?

A constructor is a special block of code used to initialize an object.

A constructor is automatically called when an object is created using the new keyword.

Simple Meaning:
A constructor gives an object its initial values when the object is created.

Basic Constructor Example

class Student {

    Student() {
        System.out.println("Constructor called");
    }

}

Now create an object: 

Student student1 = new Student();
Constructor called

The constructor is automatically executed when student1 is created.

Constructor Rules

01

Constructor name must be the same as the class name.

02

A constructor does not have a return type.

03

Constructors are called automatically when objects are created.

04

A class can have more than one constructor.

05

Constructors are mainly used to initialize object data.

06

Constructors can have parameters.

Default Constructor

If you do not write any constructor in a class, Java provides a default constructor automatically. 

class Student {

    String name;
    int age;

}

Student student1 = new Student();
Because no constructor is written, Java provides a default constructor.

User-Defined Constructor

We can create our own constructor to initialize object values. 

class Student {

    String name;
    int age;

    Student() {

        name = "Keerthana";
        age = 20;

    }

}

When the object is created, the constructor assigns the initial values.

Parameterized Constructor

A parameterized constructor accepts values as parameters when the object is created. 

class Student {

    String name;
    int age;

    Student(String name, int age) {

        this.name = name;
        this.age = age;

    }

}

Now we can pass values while creating the object. 

Student student1 =
    new Student("Keerthana", 20);

Student student2 =
    new Student("Amirtha", 21);

Understanding this Keyword

The this keyword refers to the current object. 

class Student {

    String name;

    Student(String name) {

        this.name = name;

    }

}
this.name → class field
name → constructor parameter

Constructor Overloading

A class can have multiple constructors with different parameter lists. 

class Student {

    String name;
    int age;

    // Constructor 1
    Student() {
        name = "Unknown";
        age = 0;
    }

    // Constructor 2
    Student(String name) {
        this.name = name;
    }

    // Constructor 3
    Student(String name, int age) {
        this.name = name;
        this.age = age;
    }

}

Complete Constructor Program

class Student {

    String name;
    int age;

    Student(String name, int age) {

        this.name = name;
        this.age = age;

    }

    void display() {

        System.out.println("Name: " + name);
        System.out.println("Age: " + age);

    }
}

public class Main {

    public static void main(String[] args) {

        Student student1 =
            new Student("Keerthana", 20);

        student1.display();

    }
}
Name: Keerthana
Age: 20
