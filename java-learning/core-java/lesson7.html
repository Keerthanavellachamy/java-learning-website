What is Encapsulation?

Encapsulation is the process of wrapping data and methods together inside a single class.

Simple Meaning:

Encapsulation means "protect the data and control how it is accessed."

In Java, encapsulation is commonly achieved by declaring variables as private and providing public getter and setter methods.

Real-World Example

🏧 ATM

Your bank balance is protected. You cannot directly change the balance. You use controlled operations such as deposit and withdrawal.

📱 Mobile

Internal components are protected. Users interact with the mobile through controlled buttons and applications.

🏦 Bank Account

Account information can be kept private and accessed through specific methods.

Data Hiding

Data hiding means preventing direct access to important variables from outside the class. 

class Student {

    private int marks;

}
Because marks is private, it cannot be directly accessed from outside the Student class.

Getter Method

A getter method is used to read the value of a private variable. 

public int getMarks() {

    return marks;

}
The method starts with get followed by the variable name.

Setter Method

A setter method is used to change the value of a private variable. 

public void setMarks(int marks) {

    this.marks = marks;

}
The this keyword refers to the current object's variable.

Complete Encapsulation Example

class Student {

    private int marks;

    public void setMarks(int marks) {
        this.marks = marks;
    }

    public int getMarks() {
        return marks;
    }
}


public class Main {

    public static void main(String[] args) {

        Student student = new Student();

        student.setMarks(85);

        System.out.println(student.getMarks());
    }
}

Encapsulation with Validation

One important benefit of setters is that we can validate data before storing it. 

class Student {

    private int marks;

    public void setMarks(int marks) {

        if (marks >= 0 && marks <= 100) {
            this.marks = marks;
        }
    }

    public int getMarks() {
        return marks;
    }
}
Here, marks can only be stored when the value is between 0 and 100.

Access Modifiers

Modifier Access
private Accessible only inside the same class.
default Accessible within the same package.
protected Accessible in the same package and subclasses.
public Accessible from anywhere.

Benefits of Encapsulation

🔒 Data Security

Prevents direct modification of important data.

✅ Validation

Allows validation before changing values.

🛠️ Maintainability

Makes programs easier to modify and maintain.

🎯 Controlled Access

Controls how data is read and changed.

📦 Organization

Keeps data and related methods together.

🧩 Flexibility

Internal implementation can be changed without affecting outside code.

Encapsulation vs Abstraction

Encapsulation Abstraction
Protects and controls data access. Hides unnecessary implementation details.
Focuses on how data is protected. Focuses on what should be exposed.
Commonly uses private variables, getters and setters. Commonly uses abstract classes and interfaces.

Important Rules

1. Keep important variables private.

2. Use getter methods to read values.

3. Use setter methods to modify values.

4. Validation can be added inside setters.

5. Encapsulation provides controlled access to class data.
