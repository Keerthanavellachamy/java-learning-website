What is a Class?

A class is a blueprint or template used to create objects.

A class can contain variables called fields and functions called methods.

Simple Example: A house blueprint describes the structure of a house. In the same way, a Java class describes the structure of an object. 
class Student {

    String name;
    int age;

}

Fields

Fields are variables declared inside a class. They represent the properties or characteristics of an object. 

class Student {

    String name;
    int age;
    String department;

}
Field Meaning
name Stores the student's name
age Stores the student's age
department Stores the student's department

What is an Object?

An object is a real instance of a class. It contains actual values for the fields defined inside the class.

Remember:

Class → Blueprint
Object → Actual thing created from the blueprint

Creating an Object

In Java, we commonly create an object using the new keyword. 

Student student1 = new Student();

Here:

Student

The class type.

student1

Reference variable used to access the object.

new

Creates a new object.

Student()

Calls the class constructor.

Accessing Object Fields

We can use the dot . operator to access fields of an object. 

class Student {

    String name;
    int age;

}

Student student1 = new Student();

student1.name = "Keerthana";
student1.age = 20;

System.out.println(student1.name);
System.out.println(student1.age);
Keerthana
20

Methods Inside a Class

A method defines an action that an object can perform. Methods are written inside a class. 

class Student {

    String name;

    void displayName() {
        System.out.println(name);
    }

}

We can call the method using the object. 

Student student1 = new Student();

student1.name = "Keerthana";

student1.displayName();

Multiple Objects

One class can be used to create many objects. Each object can have different values. 

Student student1 = new Student();
Student student2 = new Student();

student1.name = "Keerthana";
student1.age = 20;

student2.name = "Amirtha";
student2.age = 21;

System.out.println(student1.name);
System.out.println(student2.name);
Keerthana
Amirtha
