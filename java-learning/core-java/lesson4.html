What is Inheritance?

Inheritance is an OOP feature where one class can acquire properties and methods from another class.

Simple Meaning:

A child class can reuse code that already exists in a parent class.

Inheritance helps reduce duplicate code and makes programs easier to organize.

Real-World Example

🚗 Vehicle

A vehicle can have common features such as speed and fuel.

🚗 Car

A car can inherit common features from Vehicle.

🏍️ Bike

A bike can also inherit common features from Vehicle.

Vehicle → Parent Class
Car → Child Class
Bike → Child Class

Basic Inheritance

Java uses the extends keyword to create inheritance between classes. 

class Vehicle {

    void start() {
        System.out.println("Vehicle is starting");
    }

}

class Car extends Vehicle {

    void drive() {
        System.out.println("Car is driving");
    }

}
Car inherits the start() method from Vehicle.

Using an Inherited Method

A child class object can use methods inherited from its parent class. 

Car car1 = new Car();

car1.start();
car1.drive();
Vehicle is starting
Car is driving

Adding New Features

A child class can use inherited methods and can also define its own methods. 

class Vehicle {

    void start() {
        System.out.println("Vehicle starts");
    }

}

class Car extends Vehicle {

    void openDoor() {
        System.out.println("Car door opened");
    }

}

The Car class now has both the inherited start() method and its own openDoor() method.

Single Inheritance

Single inheritance means one child class inherits from one parent class. 

class Animal {

    void eat() {
        System.out.println("Animal eats");
    }

}

class Dog extends Animal {

    void bark() {
        System.out.println("Dog barks");
    }

}

Multilevel Inheritance

Multilevel inheritance occurs when a class inherits from another child class.

Animal → Dog → Puppy 
class Animal {

    void eat() {
        System.out.println("Eating");
    }

}

class Dog extends Animal {

    void bark() {
        System.out.println("Barking");
    }

}

class Puppy extends Dog {

    void play() {
        System.out.println("Playing");
    }

}

Hierarchical Inheritance

Hierarchical inheritance occurs when multiple child classes inherit from the same parent class.

Inheritance Types in Java

Type Meaning
Single One parent and one child
Multilevel Inheritance through multiple levels
Hierarchical Multiple children from one parent
Multiple One class inheriting from multiple classes
Java does not support multiple inheritance through classes. Multiple inheritance can be achieved using interfaces.

Benefits of Inheritance

♻️ Code Reuse

Reuse existing methods and properties from a parent class.

📦 Organization

Related classes can be organized into a clear hierarchy.

🛠️ Maintenance

Common functionality can be maintained in one parent class.

📈 Extensibility

Child classes can add their own special features.
