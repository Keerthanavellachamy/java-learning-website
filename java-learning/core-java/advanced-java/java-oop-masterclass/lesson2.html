What is a Class?

A class is a blueprint or template used to create objects.

A class defines what data an object will have and what actions the object can perform.

Real-world example: Think about a house blueprint.

The blueprint is like a class.
The actual houses built from that blueprint are objects.

What is an Object?

An object is an actual instance of a class.

When we create an object using the new keyword, Java allocates memory for that object.

Class

Blueprint or template.

Object

Actual instance created from the class.

Creating a Class

Let's create a simple class called Student.

Student.java 
class Student {

    String name;

    int age;

}

Here, Student is the class. It contains two variables: name and age.

Creating an Object

We can create an object from the Student class using the new keyword.

Main.java 
public class Main {

    public static void
    main(String[] args) {

        Student student =
            new Student();

        student.name = "Keerthana";

        student.age = 20;

        System.out.println(student.name);

        System.out.println(student.age);
    }
}
Output:

Keerthana
20

Parts of a Class

A Java class can contain different types of members.

Member Purpose Example
Field Stores data String name;
Method Performs an action display();
Constructor Initializes an object Student()
Class Defines the object structure class Student

Class with a Method

A class can contain methods that define the behavior of its objects.

Student.java 
class Student {

    String name;

    void displayDetails() {

        System.out.println(
            "Student: " + name
        );
    }
}

Now we can call the method using an object.

Main.java 
public class Main {

    public static void
    main(String[] args) {

        Student student =
            new Student();

        student.name = "Keerthana";

        student.displayDetails();
    }
}
Output:

Student: Keerthana

Creating Multiple Objects

One class can be used to create many different objects.

Main.java 
public class Main {

    public static void
    main(String[] args) {

        Student student1 =
            new Student();

        Student student2 =
            new Student();

        student1.name = "Keerthana";

        student2.name = "Amirtha";

        student1.displayDetails();

        student2.displayDetails();
    }
}
Output:

Student: Keerthana
Student: Amirtha

The new Keyword

The new keyword is used to create an object of a class.

Example 
Student student =
    new Student();
Remember:

Student → class type
student → reference variable
new Student() → creates the object
