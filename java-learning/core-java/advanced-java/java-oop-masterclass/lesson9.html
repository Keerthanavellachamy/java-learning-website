What Are Types of Inheritance?

Inheritance describes how one class gets properties and behaviors from another class. Java supports different inheritance structures depending on how the parent and child classes are connected.

Parent Class
→
Child Class

The main inheritance types you should know are Single, Multilevel, Hierarchical, Multiple, and Hybrid inheritance.

Single Inheritance

In single inheritance, one child class inherits from one parent class.

Animal
→
Dog
SingleInheritance.java 
class Animal {

    void eat() {
        System.out.println("Animal is eating");
    }
}

class Dog extends Animal {

    void bark() {
        System.out.println("Dog is barking");
    }
}
Animal is eating Dog is barking

Multilevel Inheritance

In multilevel inheritance, a class inherits from another class, and a third class inherits from the second class.

Animal
→
Dog
→
Puppy
MultilevelInheritance.java 
class Animal {

    void eat() {
        System.out.println("Eating");
    }
}

class Dog extends Animal {

    void bark() {
        System.out.println("Barking");
    }
}

class Puppy extends Dog {

    void play() {
        System.out.println("Playing");
    }
}
Puppy can access methods from both Dog and Animal because inheritance passes through multiple levels.

Hierarchical Inheritance

In hierarchical inheritance, multiple child classes inherit from the same parent class.

Animal
↙          ↘
Dog          Cat
HierarchicalInheritance.java 
class Animal {

    void eat() {
        System.out.println("Eating");
    }
}

class Dog extends Animal {

    void bark() {
        System.out.println("Barking");
    }
}

class Cat extends Animal {

    void meow() {
        System.out.println("Meowing");
    }
}
Dog and Cat both inherit the eat() method from Animal, but each class can also have its own behavior.

Multiple Inheritance

Multiple inheritance means a class tries to inherit from more than one parent class.

Class A
Class B
→
Class C

Java does not support multiple inheritance using classes.

Invalid Java Example 
// This is NOT allowed in Java

class A {
}

class B {
}

// Compilation error
class C extends A, B {
}
Java avoids this problem because multiple parent classes can create ambiguity when they contain methods with the same name. Java uses interfaces to provide multiple inheritance of type and behavior.

Hybrid Inheritance

Hybrid inheritance is a combination of two or more types of inheritance.

A
↓
B
↙      ↘
C      D

Java does not directly support hybrid inheritance through classes because it could involve multiple inheritance.

Complex inheritance structures can be designed using interfaces. We will study interfaces in later lessons.

Important Points

  • Single inheritance has one parent and one child.
  • Multilevel inheritance has multiple levels.
  • Hierarchical inheritance has multiple children from one parent.
  • Java does not support multiple inheritance using classes.
  • Java does not directly support hybrid inheritance using classes.
  • The extends keyword is used for class inheritance.
  • Interfaces can help achieve multiple inheritance of type and behavior.

Create a Java program that demonstrates hierarchical inheritance.

Try It Yourself 
class Vehicle {

    void start() {
        System.out.println("Vehicle starts");
    }
}

class Car extends Vehicle {

    void drive() {
        System.out.println("Car is driving");
    }
}

class Bike extends Vehicle {

    void ride() {
        System.out.println("Bike is riding");
    }
}

public class Main {

    public static void main(String[] args) {

        Car car = new Car();
        car.start();
        car.drive();

        Bike bike = new Bike();
        bike.start();
        bike.ride();
    }
}

Lesson Summary

In this lesson, you learned that inheritance can be organized into different structures. Java supports single, multilevel, and hierarchical inheritance using classes. Multiple and hybrid inheritance are not directly supported through classes, but interfaces can be used to create more flexible designs.

Remember:
Single → One parent, one child
Multilevel → Parent → Child → Grandchild
Hierarchical → One parent, multiple children
Multiple → Not supported with classes
