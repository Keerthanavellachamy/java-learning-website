Understanding Inheritance

Learn how one Java class can acquire properties and methods from another class using inheritance.

What is Inheritance?

Inheritance is an OOP feature that allows one class to acquire the properties and behaviors of another class.


The existing class is called the parent class, while the new class is called the child class.

Simple idea:

A child class can reuse code from its parent class.

Parent Class and Child Class

Parent Class

The class whose properties and methods are inherited is called the parent class.


It is also known as the superclass.

Child Class

The class that inherits properties and methods from another class is called the child class.


It is also known as the subclass.

The extends Keyword

Java uses the extends keyword to create inheritance between classes. 

class Animal {

    void eat() {

        System.out.println(
            "Animal is eating"
        );
    }
}

class Dog extends Animal {

    void bark() {

        System.out.println(
            "Dog is barking"
        );
    }
}
Dog inherits the eat() method from Animal.

Basic Inheritance Example

class Animal {

    void eat() {

        System.out.println(
            "Animal is eating"
        );
    }
}

class Dog extends Animal {

    void bark() {

public class Main {

    public static void main(
        String[] args
    ) {

        Dog dog =
            new Dog();

        dog.eat();
        dog.bark();
    }
}
Animal is eating Dog is barking

Code Reusability

One of the biggest advantages of inheritance is code reuse.

Without Inheritance

You may have to write the same method in multiple classes.

With Inheritance

Common functionality can be written once in the parent class and reused by child classes.

Multilevel Inheritance

In multilevel inheritance, one class inherits from another class, and a third class inherits from the second class. 

class Animal {

    void eat() {
        System.out.println("Eating");
    }
}

class Dog extends Animal {

    void bark() {
        System.out.println("Barking");
    }
}

class Puppy extends Dog {

    void play() {
        System.out.println("Playing");
    }
}
Puppy can access methods from both Dog and Animal through the inheritance chain.

Real-World Example

Vehicle → Car

A Vehicle may have common methods such as start() and stop(). A Car can inherit these methods and add its own features.

Person → Student

A Person may have name and age. A Student can inherit these properties and add course and college information.

Person and Student Example

class Person {

    String name;
    int age;

    void displayPerson() {

        System.out.println(name);
        System.out.println(age);
    }
}

class Student extends Person {

    String course;

    void displayStudent() {

        System.out.println(course);
    }
}

public class Main {

    public static void main(
        String[] args
    ) {

        Student student =
            new Student();

        student.name = "Keerthana";
        student.age = 20;
        student.course = "ECE";

        student.displayPerson();
        student.displayStudent();
    }
}
Keerthana 20 ECE

What Can Be Inherited?

Instance Methods

Accessible by the child class when inheritance rules allow it.

Instance Variables

Fields from the parent can be available to the child according to their access level.

Protected Members

Protected members can be accessed by subclasses under Java's access rules.

Constructors

Constructors are not inherited, but a child constructor can invoke a parent constructor.

Inheritance and Access Modifiers

Modifier Child Class Access
public Accessible
protected Accessible in subclass
default Accessible when in the same package
private Not directly accessible

Advantages of Inheritance

Code Reusability

Reuse existing code from a parent class.

Less Duplicate Code

Common functionality only needs to be written once.

Easy Maintenance

Common behavior can be managed in the parent class.

Supports Polymorphism

Inheritance provides the foundation for many polymorphism concepts.

Important Points

  • Inheritance allows one class to acquire features from another class.
  • The existing class is called the parent or superclass.
  • The new class is called the child or subclass.
  • Java uses the extends keyword for class inheritance.
  • Inheritance promotes code reusability.
  • Constructors are not inherited.
  • Private members are not directly accessible in a child class.
  • Java classes support single, multilevel and hierarchical inheritance.
