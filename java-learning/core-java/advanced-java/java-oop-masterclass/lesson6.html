Understanding Static Members

Learn how static variables, methods and blocks belong to the class instead of individual objects, and understand when and why to use them.

static
Lesson 6 of 30 20% Complete

What is static?

The static keyword in Java is used for members that belong to the class rather than to individual objects.

Simple idea:

Normal members belong to objects.
Static members belong to the class.

Types of Static Members

01. Static Variable

A variable shared by all objects of the class.

02. Static Method

A method that can be called using the class name without creating an object.

03. Static Block

A block that runs when the class is loaded.

04. Static Nested Class

A nested class declared using the static keyword.

Static Variable

A static variable is shared among all objects created from the class. 

class Student {

    String name;

    static String college = "Meenakshi College";
}
Here, name is different for each object, but college is shared by every Student object.

Example of Static Variable

class Student {

    String name;

    static String college = "MCE";

    Student(String name) {
        this.name = name;
    }

    void display() {
        System.out.println(name);
        System.out.println(college);
    }
}

public class Main {

    public static void main(String[] args) {

        Student s1 =
            new Student("Keerthana");

        Student s2 =
            new Student("Amirtha");

        s1.display();
        s2.display();
    }
}
Keerthana MCE Amirtha MCE

Accessing a Static Variable

A static member can be accessed using the class name. 

class Student {

    static String college = "MCE";
}

public class Main {

    public static void main(String[] args) {

        System.out.println(
            Student.college
        );
    }
}
MCE

Static Method

A static method belongs to the class. You do not need to create an object to call it. 

class Calculator {

    static int add(int a, int b) {

        return a + b;
    }
}

public class Main {

    public static void main(String[] args) {

        int result =
            Calculator.add(10, 20);

        System.out.println(result);
    }
}

Rules of Static Methods

  • A static method belongs to the class.
  • It can be called using the class name.
  • You do not need an object to call it.
  • It can directly access static variables.
  • It cannot directly access non-static instance variables.
  • It cannot directly use the this keyword.

Static vs Instance Members

Static Member Instance Member
Belongs to the class Belongs to an object
One shared copy Each object has its own copy
Can use class name Usually accessed using an object
Object is not required Object is required
Cannot directly use this Can use this

Static Block

A static block is used to initialize static data. It executes when the class is loaded. 

class Demo {

    static {

        System.out.println(
            "Static block executed"
        );
    }
}

public class Main {

    public static void main(String[] args) {

        Demo d =
            new Demo();
    }
}

Real-World Example

College Name

Every student may belong to the same college. Therefore, the college name can be stored as a static variable.

Student Counter

A static counter can keep track of the total number of Student objects created.

Static Counter Example

class Student {

    static int count = 0;

    Student() {

        count++;
    }
}

public class Main {

    public static void main(String[] args) {

        new Student();
        new Student();
        new Student();

        System.out.println(
            Student.count
        );
    }
}

Important Points

  • static means the member belongs to the class.
  • Static variables are shared by all objects.
  • Static methods can be called using the class name.
  • Static members can be accessed without creating an object.
  • A static method cannot directly access instance variables.
  • A static method cannot directly use this.
  • Static blocks execute when the class is loaded.
