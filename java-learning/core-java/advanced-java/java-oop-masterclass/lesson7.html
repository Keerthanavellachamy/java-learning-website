Understanding Encapsulation

Learn how encapsulation protects data inside a class and provides controlled access through methods such as getters and setters.

What is Encapsulation?

Encapsulation is one of the four major principles of Object-Oriented Programming.


It means wrapping data and the methods that operate on that data together inside a class while restricting direct access to the internal data.

Simple idea:

Keep data private and provide controlled access through public methods.

Four Pillars of OOP

01. Encapsulation

Protects data and controls access to it.

02. Inheritance

Allows one class to acquire properties and behavior from another class.

03. Polymorphism

Allows one interface or method name to have different forms.

04. Abstraction

Hides unnecessary implementation details and exposes only essential features.

Why Do We Need Encapsulation?

Data Protection

Important data can be protected from unwanted direct modification.

Controlled Access

We can decide how other classes can read or change the data.

Better Security

Internal implementation details can remain hidden from other parts of the program.

Easy Maintenance

Internal implementation can change without changing how other classes use the object.

Without Encapsulation

If variables are public, another class can directly modify them. 

class Student {

    public String name;
    public int age;
}

public class Main {

    public static void main(String[] args) {

        Student student =
            new Student();

        student.age = -10;
    }
}
The problem is that the program allows an invalid age. There is no control over how the data is changed.

Using private Variables

A common way to achieve encapsulation is to declare variables as private. 

class Student {

    private String name;
    private int age;
}
A private variable cannot be accessed directly from outside the class.

Getter Method

A getter is a method used to read the value of a private variable. 

class Student {

    private String name;

    public String getName() {

        return name;
    }
}
Getter = Read data

The method returns the private value without exposing the variable directly.

Setter Method

A setter is a method used to change the value of a private variable. 

class Student {

    private String name;

    public void setName(String name) {

        this.name = name;
    }
}
Setter = Modify data

A setter allows controlled modification of a private field.

Complete Encapsulation Example

class Student {

    private String name;
    private int age;

    public void setName(String name) {
        this.name = name;
    }

    public String getName() {
        return name;
    }

    public void setAge(int age) {

        if (age >= 18) {
            this.age = age;
        }
    }

    public int getAge() {
        return age;
    }
}

public class Main {

    public static void main(String[] args) {

        Student student =
            new Student();

        student.setName("Keerthana");
        student.setAge(20);

        System.out.println(student.getName());
        System.out.println(student.getAge());
    }
}
Keerthana 20

Data Validation

One major benefit of encapsulation is that setters can validate data before storing it. 

public void setAge(int age) {

    if (age >= 18 && age <= 60) {

        this.age = age;

    } else {

        System.out.println(
            "Invalid age"
        );
    }
}
The setter controls the data and prevents invalid values from entering the object.

Real-World Example

Bank Account

A bank account balance should not be directly changed by anyone. Methods such as deposit() and withdraw() can control the balance.

Student Details

Student marks can be private, while setter methods can make sure that marks stay within a valid range.

Getter vs Setter

Getter Setter
Reads data Changes data
Usually starts with get Usually starts with set
Returns a value Usually returns void
Does not normally modify the field Modifies the field

How to Implement Encapsulation

  1. Declare class variables as private.
  2. Create public getter methods to read the values.
  3. Create public setter methods to modify the values.
  4. Add validation inside setters when required.
  5. Access the data through methods instead of directly.

Important Points

  • Encapsulation protects the internal data of an object.
  • Private variables cannot be directly accessed outside the class.
  • Getters are generally used to read private data.
  • Setters are generally used to modify private data.
  • Setters can validate values before assigning them.
  • Encapsulation improves security and maintainability.
  • Encapsulation gives controlled access to object data.
