What are Fields and Methods?

A Java class normally contains data and behavior.

Fields represent the data or properties of an object.

Methods represent the behavior or actions that an object can perform.

Think about a Student object.

Fields: name, age, department
Methods: study(), attendClass(), displayDetails()

What is a Field?

A field is a variable declared inside a class. It stores information about an object.

Student.java 
class Student {

    String name;

    int age;

    String department;

}

In this example, name, age, and department are fields.

Common Field Data Types

String

Stores text values. Example: "Keerthana"

int

Stores whole numbers. Example: 20

double

Stores decimal values. Example: 8.15

boolean

Stores true or false.

What is a Method?

A method is a block of code that performs a particular task.

Methods allow us to define the behavior of an object.

Student.java 
class Student {

    void study() {

        System.out.println(
            "Student is studying"
        );
    }
}
Output:

Student is studying

Method Syntax

A basic Java method follows this structure:

Method Syntax 
returnType methodName(parameters) {

    // code to execute

}
Part Meaning
returnType Type of value returned by the method
methodName Name used to call the method
parameters Input values given to the method
method body Code executed by the method

Void Methods

A method with the return type void does not return a value.

Example 
void greet() {

    System.out.println(
        "Welcome to Java!"
    );
}

Methods That Return Values

A method can calculate something and return a value.

Calculator.java 
class Calculator {

    int add(
        int a,
        int b
    ) {

        return a + b;
    }
}

We can call the method and store its returned value.

Main.java 
Calculator calculator =
    new Calculator();

int result =
    calculator.add(10, 20);

System.out.println(result);
Output:

30

Methods with Parameters

Parameters allow us to send data into a method.

Student.java 
class Student {

    void greet(
        String name
    ) {

        System.out.println(
            "Hello " + name
        );
    }
}
Main.java 
Student student =
    new Student();

student.greet(
    "Keerthana"
);
Output:

Hello Keerthana

Fields and Methods Together

Fields and methods work together to describe the state and behavior of an object.

Student.java 
class Student {

    String name;

    int age;

    void displayDetails() {

        System.out.println(
            "Name: " + name
        );

        System.out.println(
            "Age: " + age
        );
    }
}
Main.java 
Student student =
    new Student();

student.name =
    "Keerthana";

student.age = 20;

student.displayDetails();
Output:

Name: Keerthana
Age: 20

Field vs Method

Field Method
Stores data Performs an action
Represents state Represents behavior
Example: name Example: displayName()
Usually accessed using object Called using object

Lesson Summary

  • Fields store the data of an object.
  • Methods define the behavior of an object.
  • A method can accept parameters.
  • A method can return a value.
  • The void keyword means the method does not return a value.
  • Fields and methods together define the state and behavior of an object.
