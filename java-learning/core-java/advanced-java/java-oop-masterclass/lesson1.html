What is Object-Oriented Programming?

Object-Oriented Programming, commonly called OOP, is a programming approach where programs are designed using objects and classes.

An object represents something that contains data and behavior.

Simple Example: A Car can be considered an object.

Data → color, model, speed
Behavior → start(), stop(), accelerate()

Why Do We Use OOP?

OOP helps developers organize large programs into smaller and reusable components.

1. Reusability

Code can be reused using classes, inheritance and other OOP concepts.

2. Maintainability

Large applications become easier to understand and maintain.

3. Security

Encapsulation helps protect important data from direct access.

4. Flexibility

Polymorphism allows the same interface to behave differently.

The Four Pillars of OOP

Java OOP is mainly based on four important concepts.

Encapsulation

Wrapping data and methods together inside a class.

Inheritance

Creating a new class from an existing class.

Polymorphism

One interface or method can have different behaviors.

Abstraction

Hiding unnecessary implementation details and showing only essential features.

Your First OOP Example

Let's create a simple Java class representing a car.

Main.java 
class Car {

    String color = "Red";

    void drive() {

        System.out.println(
            "The car is driving"
        );
    }
}


public class Main {

    public static void
    main(String[] args) {

        Car car = new Car();

        System.out.println(car.color);

        car.drive();
    }
}
Output:

Red
The car is driving

Important OOP Terms

  • Class: A blueprint for creating objects.
  • Object: An instance of a class.
  • Method: A block of code that performs an action.
  • Field: A variable defined inside a class.
  • Constructor: A special method used when creating an object.
