Understanding the this Keyword

Learn how the this keyword refers to the current object and how it helps you work with instance variables, methods, constructors and objects.

What is the this Keyword?

In Java, this is a special keyword that refers to the current object.

Think of this as saying:

"This particular object"

It is commonly used when an instance variable and a parameter have the same name.

Why Use this?

01. Access Instance Variables

Use this to clearly refer to the current object's instance variables.

02. Resolve Variable Shadowing

It helps distinguish an instance variable from a constructor or method parameter.

03. Call Current Class Methods

You can use this.methodName() to call a method of the current object.

04. Call Another Constructor

The this() syntax can call another constructor in the same class.

this with Instance Variables

One of the most common uses of this is to distinguish instance variables from parameters. 

class Student {

    String name;
    int age;

    Student(String name, int age) {

        this.name = name;
        this.age = age;
    }
}
this.name → instance variable of the current object
name → constructor parameter

The same applies to this.age and age.

Using this in an Object

Student student =
    new Student("Keerthana", 20);

System.out.println(student.name);
System.out.println(student.age);
Keerthana 20

this with Methods

We can use this to call a method belonging to the current object. 

class Student {

    void display() {
        System.out.println("Student details");
    }

    void show() {
        this.display();
    }
}
Here, this.display() means:

"Call the display() method of the current Student object."

this() to Call Another Constructor

Java allows one constructor to call another constructor in the same class using this(). 

class Student {

    String name;
    int age;

    Student() {
        this("Unknown", 0);
    }

    Student(String name, int age) {
        this.name = name;
        this.age = age;
    }
}
Important:
this() must always be the first statement inside a constructor.

Passing this as an Argument

The current object can also be passed to another method using this. 

class Student {

    String name = "Keerthana";

    void display(Student student) {
        System.out.println(student.name);
    }

    void show() {
        display(this);
    }
}
Keerthana

Here, this represents the current Student object and is passed to display().

Returning this

A method can return the current object using return this;. 

class Student {

    Student getStudent() {
        return this;
    }
}
Returning this is useful when building methods that support method chaining.

this Cannot Be Used in static

The this keyword refers to an object. A static method belongs to the class rather than a particular object. 

class Test {

    int value = 10;

    static void display() {

        // this.value;  // Error
    }
}
Remember:

Instance members belong to objects. Static members belong to the class. Therefore, this cannot be used directly inside a static context.

this vs Normal Variable

Expression Meaning
this.name Current object's instance variable
name Local variable or parameter
this.display() Calls the current object's method
this() Calls another constructor in the same class
return this Returns the current object

Important Points

  • this refers to the current object.
  • It is mainly used with instance members.
  • It resolves confusion between fields and parameters.
  • this.method() calls a method of the current object.
  • this() calls another constructor.
  • this() must be the first statement in a constructor.
  • return this; returns the current object.
  • this cannot be directly used in a static context.
