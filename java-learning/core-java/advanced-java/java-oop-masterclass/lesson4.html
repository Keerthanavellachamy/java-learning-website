Understanding Constructors

Learn how constructors initialize objects when they are created and understand default, parameterized and overloaded constructors.

What is a Constructor?

A constructor is a special member of a class that is automatically called when an object is created.

Constructors are mainly used to initialize the fields of an object.

Simple idea:

When you create an object:

new Student()

Java calls the constructor of the Student class.

Rules of a Constructor

1. Same Name

A constructor must have the same name as its class.

2. No Return Type

A constructor does not have a return type, not even void.

3. Called Automatically

Java automatically calls it when an object is created.

4. Initializes Objects

It is commonly used to initialize object fields.

Creating a Constructor

Here is a simple Student class with a constructor.

Student.java 
class Student {

    String name;

    // Constructor

    Student() {

        name = "Keerthana";
    }
}

When the object is created, the constructor automatically assigns the value to name.

Calling the Constructor

Main.java 
public class Main {

    public static void
    main(String[] args) {

        Student student =
            new Student();

        System.out.println(
            student.name
        );
    }
}
Output:

Keerthana

Default Constructor

If you do not write any constructor in your class, Java can provide a default constructor automatically.

Student.java 
class Student {

    String name;

    int age;
}

Java provides a no-argument constructor behind the scenes because no constructor has been declared.

⚠️ Important:

If you create your own constructor, Java does not automatically add the no-argument constructor.

Parameterized Constructor

A parameterized constructor accepts values when the object is created.

Student.java 
class Student {

    String name;

    int age;

    Student(String studentName, int studentAge) {

        name = studentName;

        age = studentAge;
    }
}

Using a Parameterized Constructor

Main.java 
public class Main {

    public static void
    main(String[] args) {

        Student student =
            new Student(
                "Keerthana",
                20
            );

        System.out.println(student.name);

        System.out.println(student.age);
    }
}
Output:

Keerthana
20

Constructor with Multiple Objects

A parameterized constructor allows us to create different objects with different values.

Main.java 
Student student1 =
    new Student(
        "Keerthana",
        20
    );

Student student2 =
    new Student(
        "Amirtha",
        21
    );

System.out.println(student1.name);

System.out.println(student2.name);
Output:

Keerthana
Amirtha

Constructor Overloading

A class can have more than one constructor as long as their parameter lists are different.

Student.java 
class Student {

    String name;

    int age;


    // Constructor 1

    Student() {

        name = "Unknown";

        age = 0;
    }


    // Constructor 2

    Student(String name) {

        this.name = name;

        age = 0;
    }


    // Constructor 3

    Student(String name, int age) {

        this.name = name;

        this.age = age;
    }
}

Constructor vs Method

Constructor Method
Initializes an object Performs an operation
Same name as class Can have any valid name
No return type Can have a return type
Called when object is created Called explicitly

Important Points

  • A constructor has the same name as its class.
  • A constructor has no return type.
  • Constructors initialize objects.
  • Java can provide a default constructor if no constructor is declared.
  • Parameterized constructors accept values.
  • Multiple constructors are possible through constructor overloading.
