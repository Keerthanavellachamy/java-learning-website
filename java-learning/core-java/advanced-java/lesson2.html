What is File Handling?

File Handling means performing operations on files using a programming language.


In Java, file handling allows us to create files, write data, read data, update data and delete files.

💡 Simple idea: A file is used to permanently store information. Java provides classes to work with those files.

File Class

Java provides the File class inside the java.io package. 

import java.io.File;

The File class is used to represent a file or directory in the computer.

Creating a File

We can create a new file using the createNewFile() method. 

import java.io.File;
import java.io.IOException;

public class Main {

    public static void main(String[] args) {

        File file =
            new File("example.txt");

        try {

            if (file.createNewFile()) {

                System.out.println(
                    "File created successfully"
                );

            } else {

                System.out.println(
                    "File already exists"
                );
            }

        } catch (IOException e) {

            System.out.println(
                "An error occurred"
            );
        }
    }
}
File created successfully

Writing to a File

The FileWriter class is used to write text into a file. 

import java.io.FileWriter;
import java.io.IOException;

public class Main {

    public static void main(String[] args) {

        try {

            FileWriter writer =
                new FileWriter(
                    "example.txt"
                );

            writer.write(
                "Welcome to JavaLearn!"
            );

            writer.close();

            System.out.println(
                "Data written successfully"
            );

        } catch (IOException e) {

            System.out.println(
                "An error occurred"
            );
        }
    }
}
Data written successfully

Reading a File

We can read a file using BufferedReader and FileReader. 

import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;

public class Main {

    public static void main(String[] args) {

        try {

            BufferedReader reader =
                new BufferedReader(
                    new FileReader(
                        "example.txt"
                    )
                );

            String line;

            while (
                (line = reader.readLine()) != null
            ) {

                System.out.println(line);
            }

            reader.close();

        } catch (IOException e) {

            System.out.println(
                "An error occurred"
            );
        }
    }
}

Reading Using Scanner

For beginners, Scanner is another simple way to read data from a file. 

import java.io.File;
import java.io.FileNotFoundException;
import java.util.Scanner;

public class Main {

    public static void main(String[] args) {

        try {

            File file =
                new File(
                    "example.txt"
                );

            Scanner scanner =
                new Scanner(file);

            while (scanner.hasNextLine()) {

                System.out.println(
                    scanner.nextLine()
                );
            }

            scanner.close();

        } catch (
            FileNotFoundException e
        ) {

            System.out.println(
                "File not found"
            );
        }
    }
}

Important File Methods

Method Purpose
createNewFile() Creates a new file
exists() Checks whether the file exists
getName() Returns the file name
getAbsolutePath() Returns the complete file path
length() Returns file size
delete() Deletes the file

Checking if File Exists

File file =
    new File("example.txt");

if (file.exists()) {

    System.out.println(
        "File exists"
    );

} else {

    System.out.println(
        "File does not exist"
    );
}

Getting File Information

File file =
    new File("example.txt");

System.out.println(file.getName());

System.out.println(
    file.getAbsolutePath()
);

System.out.println(
    file.length()
);
💡 Remember: getName() gives the file name, while getAbsolutePath() gives the complete location of the file.

Appending Data

Normally, FileWriter replaces the existing content. To add new content at the end, use true. 

FileWriter writer =
    new FileWriter(
        "example.txt",
        true
    );

writer.write(
    "\nLearning Advanced Java"
);

writer.close();
💡 true means append the new data instead of replacing the existing data.

Deleting a File

The delete() method removes a file. 

import java.io.File;

public class Main {

    public static void main(String[] args) {

        File file =
            new File(
                "example.txt"
            );

        if (file.delete()) {

            System.out.println(
                "File deleted successfully"
            );

        } else {

            System.out.println(
                "File could not be deleted"
            );
        }
    }
}
File deleted successfully

Exceptions in File Handling

IOException

Occurs when an input or output operation has a problem.

FileNotFoundException

Occurs when Java cannot find the required file.

try-catch

Used to handle exceptions and prevent the program from stopping unexpectedly.

Why try-catch?

File operations can produce errors. For example, the file may not exist or the program may not have permission to access it.

💡 Simple idea: try = "Try to perform the operation."
catch = "If something goes wrong, handle the error."

Important Rules

  1. Import the required Java classes.
  2. Use try-catch for operations that may throw exceptions.
  3. Close readers and writers after use.
  4. Check whether the file exists when necessary.
  5. Use the correct file path.
  6. Use append mode when you want to keep old data.
