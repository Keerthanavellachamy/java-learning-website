What is a Thread?

A thread is a small unit of execution inside a program.


It represents a task that a program can perform.

💡 Simple example: Imagine you are using a music application. One task can play music while another task downloads a song. These tasks can work using different threads.

What is Multithreading?

Multithreading means executing multiple threads within a program.


Instead of waiting for one task to completely finish, different tasks can make progress concurrently.

Creating a Thread

One way to create a thread is by extending the Thread class. 

class MyThread extends Thread {

    public void run() {

        System.out.println(
            "Thread is running"
        );
    }
}

public class Main {

    public static void main(String[] args) {

        MyThread thread =
            new MyThread();

        thread.start();
    }
}
Thread is running

run() Method

The run() method contains the code that the thread should execute. 

class MyThread extends Thread {

    public void run() {

        System.out.println(
            "Hello from thread"
        );
    }
}
💡 Think of run() as the work performed by the thread.

start() Method

The start() method starts a new thread. 

MyThread thread =
    new MyThread();

thread.start();
⚠️ Important: Calling start() creates a new thread and then Java executes run().

start() vs run()

start() run()

Multiple Threads

We can create more than one thread in a Java program. 

class Task extends Thread {

    private String name;

    Task(String name) {

        this.name = name;
    }

    public void run() {

        System.out.println(
            name + " is running"
        );
    }
}

public class Main {

    public static void main(String[] args) {

        Task task1 =
            new Task("Task 1");

        Task task2 =
            new Task("Task 2");

        task1.start();
        task2.start();
    }
}
Task 1 is running
Task 2 is running
💡 The exact order of thread output can vary because the operating system decides when each thread runs.

sleep() Method

The sleep() method temporarily pauses the current thread. 

class MyThread extends Thread {

    public void run() {

        try {

            System.out.println(
                "Thread started"
            );

            Thread.sleep(2000);

            System.out.println(
                "Thread continued"
            );

        } catch (
            InterruptedException e
        ) {

            System.out.println(
                "Thread interrupted"
            );
        }
    }
}
⏱️ 2000 milliseconds = 2 seconds

Runnable Interface

Another way to create a thread is by implementing the Runnable interface. 

class MyTask
        implements Runnable {

    public void run() {

        System.out.println(
            "Runnable thread is running"
        );
    }
}

public class Main {

    public static void main(String[] args) {

        MyTask task =
            new MyTask();

        Thread thread =
            new Thread(task);

        thread.start();
    }
}
Runnable thread is running

join() Method

The join() method makes one thread wait until another thread finishes. 

Thread thread1 =
    new Thread(() -> {

        System.out.println(
            "Task 1"
        );
    });

thread1.start();

try {

    thread1.join();

} catch (
    InterruptedException e
) {

    System.out.println(
        "Interrupted"
    );
}

System.out.println(
    "Main continues"
);
💡 join() is useful when one task must finish before another task continues.

Important Points

  1. A thread represents a unit of execution.
  2. Multithreading allows multiple threads in a program.
  3. The run() method contains the thread's task.
  4. The start() method starts a new thread.
  5. sleep() temporarily pauses a thread.
  6. Runnable is another way to create a thread task.
  7. Thread execution order is not always predictable.
  8. Shared data between threads may require synchronization.
