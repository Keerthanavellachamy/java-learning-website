What is Collections Framework?

The Java Collections Framework is a set of classes and interfaces used to store and manipulate groups of objects.

Simple Meaning:

Instead of creating many separate variables, collections allow us to store multiple values together.

Why Do We Need Collections?

Suppose we want to store the marks of 5 students. 

int mark1 = 85;
int mark2 = 90;
int mark3 = 78;
int mark4 = 88;
int mark5 = 92;

This becomes difficult when we have hundreds or thousands of values. Collections make this easier.

Main Collection Types

📋 List

Stores elements in an ordered manner and allows duplicate values.

🔵 Set

Stores unique elements and normally does not allow duplicates.

🗺️ Map

Stores data using key-value pairs.

ArrayList

ArrayList is one of the most commonly used collection classes in Java. It stores elements in an ordered list. 

import java.util.ArrayList;

public class Main {

    public static void main(String[] args) {

        ArrayList<String> names
            = new ArrayList<>();

        names.add("Keerthana");
        names.add("Amirtha");
        names.add("Harshitha");

        System.out.println(names);
    }
}
[Keerthana, Amirtha, Harshitha]

ArrayList Methods

Method Purpose
add() Adds an element.
get() Gets an element.
set() Updates an element.
remove() Removes an element.
size() Returns the number of elements.

Accessing ArrayList Elements 

ArrayList<String> names
    = new ArrayList<>();

names.add("Java");
names.add("Python");
names.add("HTML");

System.out.println(names.get(0));
Java

Loop Through ArrayList

We can use a for-each loop to process every element in an ArrayList. 

for (String name : names) {

    System.out.println(name);

}

LinkedList

LinkedList is another List implementation. It stores elements as connected nodes. 

import java.util.LinkedList;

LinkedList<String> cities
    = new LinkedList<>();

cities.add("Chennai");
cities.add("Madurai");
cities.add("Coimbatore");

System.out.println(cities);
[Chennai, Madurai, Coimbatore]

HashSet

HashSet stores unique elements. Duplicate values are not stored. 

import java.util.HashSet;

HashSet<String> skills
    = new HashSet<>();

skills.add("Java");
skills.add("Python");
skills.add("Java");

System.out.println(skills);
The second Java value is a duplicate, so HashSet keeps only one copy.

HashMap

HashMap stores data using key-value pairs. 

import java.util.HashMap;

HashMap<Integer, String> students
    = new HashMap<>();

students.put(101, "Keerthana");
students.put(102, "Amirtha");
students.put(103, "Harshitha");

System.out.println(students);

Benefits of Collections

📦 Easy Storage

Store many objects together.

🔄 Easy Processing

Easily loop through and process multiple elements.

🧩 Flexible

Different collection types are available for different requirements.

⚡ Useful Methods

Collections provide built-in methods for adding, removing and searching data.

📊 Organized

Data can be organized according to the application's requirements.

💻 Practical

Collections are widely used in real-world Java applications.

Important Points

1. ArrayList stores ordered elements and allows duplicates.

2. LinkedList is another implementation of the List interface.

3. HashSet stores unique elements.

4. HashMap stores key-value pairs.

5. Collections are used to manage groups of objects.
