What is JDBC?

JDBC stands for Java Database Connectivity.


JDBC is a Java API that allows Java applications to connect to databases and execute SQL commands.

💡 Simple idea: JDBC acts like a bridge between your Java program and your database.

JDBC Flow

Java Program
↓
JDBC API
↓
MySQL Driver
↓
MySQL Database

What is MySQL?

MySQL is a relational database management system.


It stores information in tables containing rows and columns.


Example:

Step 4: MySQL JDBC Driver

Java needs a MySQL JDBC driver to communicate with MySQL.

💡 The MySQL Connector/J driver provides the JDBC support needed for Java applications to communicate with MySQL.

In a Maven project, the MySQL Connector/J dependency is normally added to pom.xml. 

<dependency>

    <groupId>com.mysql</groupId>

    <artifactId>mysql-connector-j</artifactId>

    <version>8.4.0</version>

</dependency>
⚠️ If you are using a different MySQL Connector/J version, use the version configured for your project.

Step 5: Connect Java to MySQL

The DriverManager class can be used to create a database connection. 

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.SQLException;

public class Main {

    public static void main(String[] args) {

        String url =
            "jdbc:mysql://localhost:3306/studentdb";

        String username = "root";

        String password = "your_password";

        try {

            Connection connection =
                DriverManager.getConnection(
                    url,
                    username,
                    password
                );

            System.out.println(
                "Database connected!"
            );

            connection.close();

        } catch (SQLException e) {

            e.printStackTrace();
        }
    }
}
Database connected!
💡 Replace your_password with the password configured for your MySQL account.

Step 6: Execute SQL

A Statement can be used to execute simple SQL commands. 

import java.sql.*;

public class Main {

    public static void main(String[] args) {

        String url =
            "jdbc:mysql://localhost:3306/studentdb";

        String username = "root";
        String password = "your_password";

        try {

            Connection connection =
                DriverManager.getConnection(
                    url, username, password
                );

            Statement statement =
                connection.createStatement();

            statement.executeUpdate(
                "INSERT INTO students " +
                "(id, name, age) " +
                "VALUES (2, 'Amirtha', 21)"
            );

            System.out.println(
                "Data inserted"
            );

            connection.close();

        } catch (SQLException e) {

            e.printStackTrace();
        }
    }
}
Data inserted

Important Statement Methods

Method Use
executeQuery() Used for SELECT queries
executeUpdate() Used for INSERT, UPDATE and DELETE
execute() Executes a SQL statement

Step 7: Read Data

To retrieve records from MySQL, use a SELECT query with executeQuery(). 

Statement statement =
    connection.createStatement();

ResultSet result =
    statement.executeQuery(
        "SELECT * FROM students"
    );

while (result.next()) {

    System.out.println(
        result.getInt("id")
    );

    System.out.println(
        result.getString("name")
    );

    System.out.println(
        result.getInt("age")
    );
}

What is ResultSet?

ResultSet stores the data returned by a SELECT query.


The next() method moves to the next row.

💡 Think of ResultSet like a table cursor that moves row by row through the records returned by the query.

PreparedStatement

PreparedStatement is used for parameterized SQL queries.

It is generally preferred when values come from users or application input. 

String sql =
    "INSERT INTO students " +
    "(id, name, age) VALUES (?, ?, ?)";

PreparedStatement ps =
    connection.prepareStatement(sql);

ps.setInt(1, 3);
ps.setString(2, "Harshitha");
ps.setInt(3, 20);

ps.executeUpdate();
🔐 Using parameter placeholders helps avoid treating user input as part of the SQL command itself.

⚠️ Always use a suitable WHERE condition when deleting or updating records unless you intentionally want to affect every row.

Complete JDBC Example

The following example connects to MySQL, inserts a record and reads records. 

import java.sql.*;

public class Main {

    public static void main(String[] args) {

        String url =
            "jdbc:mysql://localhost:3306/studentdb";

        String username = "root";
        String password = "your_password";

        try {

            Connection connection =
                DriverManager.getConnection(
                    url,
                    username,
                    password
                );

            String sql =
                "SELECT * FROM students";

            Statement statement =
                connection.createStatement();

            ResultSet result =
                statement.executeQuery(sql);

            while (result.next()) {

                System.out.println(
                    result.getInt("id") + " " +
                    result.getString("name") + " " +
                    result.getInt("age")
                );
            }

            connection.close();

        } catch (SQLException e) {

            e.printStackTrace();
        }
    }
}
1 Keerthana 20
2 Amirtha 21

Important Points

  1. Create the MySQL database and table first.
  2. Add the MySQL JDBC driver to your Java project.
  3. Use DriverManager to create a connection.
  4. Use Statement or PreparedStatement to execute SQL.
  5. Use ResultSet to read SELECT results.
  6. Close database resources after use.
  7. Use PreparedStatement for values supplied by users.
  8. Never expose database passwords in public repositories.
