What is an Interface?

An interface is a blueprint or contract that specifies what a class should do.

Simple Meaning:

An interface tells a class what methods it should provide, while the class provides the implementation.

Interfaces are commonly used to achieve abstraction and support multiple inheritance of type in Java.

Creating an Interface

An interface is created using the interface keyword. 

interface Animal {

    void sound();

}
Here, Animal is an interface and sound() is a method declared inside it.

Implementing an Interface

A class uses the implements keyword to implement an interface. 

interface Animal {

    void sound();

}


class Dog implements Animal {

    public void sound() {
        System.out.println("Dog barks");
    }

}

Complete Interface Example

interface Animal {

    void sound();

}


class Dog implements Animal {

    public void sound() {
        System.out.println("Dog barks");
    }

}


public class Main {

    public static void main(String[] args) {

        Dog dog = new Dog();

        dog.sound();
    }
}
Dog barks

extends vs implements

extends implements
Used for class inheritance. Used when a class implements an interface.
Class extends another class. Class implements an interface.
Example: Dog extends Animal Example: Dog implements Animal

Multiple Interfaces

A Java class can implement more than one interface. This allows a class to follow multiple contracts. 

interface Printable {

    void print();

}


interface Showable {

    void show();

}


class Demo
implements Printable, Showable {

    public void print() {
        System.out.println("Printing");
    }

    public void show() {
        System.out.println("Showing");
    }

}
Multiple interfaces are separated using a comma.

Interface Methods

In a basic interface example, methods are declared without a body and the implementing class provides the implementation. 

interface Vehicle {

    void start();

    void stop();

}

Implementing Interface Methods

class Car implements Vehicle {

    public void start() {
        System.out.println("Car starts");
    }

    public void stop() {
        System.out.println("Car stops");
    }

}
Car starts
Car stops

Variables in an Interface

Variables declared inside an interface are implicitly public, static and final. 

interface Constants {

    int MAX_SPEED = 120;

}
Interface variables cannot normally be changed after they are initialized.

Benefits of Interfaces

🔗 Abstraction

Interfaces help hide implementation details and define required behavior.

🧩 Flexibility

Different classes can provide different implementations of the same interface.

🔄 Multiple Contracts

A class can implement multiple interfaces.

📋 Common Structure

Interfaces provide a common contract for different classes.

🛠️ Maintainability

Code becomes easier to organize and maintain.

🚀 Reusability

The same interface can be implemented by many different classes.

Abstract Class vs Interface

Abstract Class Interface
Declared using abstract keyword. Declared using interface keyword.
Can contain abstract and concrete methods. Primarily defines a contract for classes.
A class extends an abstract class. A class implements an interface.
A class can extend only one class. A class can implement multiple interfaces.

Real-World Example

🚗 Vehicle

A vehicle interface can define start() and stop() methods.

💳 Payment

A payment interface can define a pay() method implemented by different payment types.

🔔 Notification

A notification interface can define send() for Email, SMS and other services.

Important Rules

1. Use the interface keyword to create an interface.

2. Use implements when a class implements an interface.

3. The implementing class must provide the required method implementations.

4. A class can implement multiple interfaces.

5. Interfaces are commonly used to achieve abstraction.
